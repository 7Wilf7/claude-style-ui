02

给内容合适的宽度

拖动中间手柄调整；聚焦手柄后按 ← / → 微调、Home / End 到边界，Enter 或双击居中。拖动中按 Escape 撤销。空间不足时，两栏自然堆叠。

整理一次周末出行

一个安静的工作区，把讨论和正在编辑的内容放在一起。需要仔细看文档时，向左调整分割线。

  • 上午出发，预留休息时间。
  • 选择适合当日状态的路线。
  • 把重要信息留在视线之内。
